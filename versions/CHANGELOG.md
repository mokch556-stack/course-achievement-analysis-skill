# CHANGELOG — course_achievement_analysis

## v5.0.0 (2026-07-01)
折合约束自动检测 + docx模板填充铁律体系 + Table0/1自适应裁剪。

- 折合权重约束自动检测：同一考核环节出现在N个目标中时，zhe_full必须均分，逐列SUM==总评
- 数据归集完整性校验：config学生数 vs 系统成绩单学生数交叉比对，缺人自动补
- docx模板填充铁律体系：原位覆写不删行、合并单元格识别、多run匹配、自适应裁剪
- Table0/Table1自适应：单班删双班区域、删重复分数段列、删多余项目作业行
- 修复：C0多run残留清理、课程性质不擅加括号、"—"占位改为删行
- 升级：分析文本铁律——合班报告独立写不提他班、四段数据驱动、≥1000字
